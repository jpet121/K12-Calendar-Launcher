Calendar Launcher

Open the launcher from its Windows command file. Keep the console open until all work finishes.

Select an environment

Use an authorized Oracle HCM test environment first. Confirm the exact HTTPS address with your administrator before entering credentials. Sign out before changing accounts.

Read and export

Connect, refresh the inventory, and choose a calendar to see its events. Export only to an approved local folder.

Build from a workbook

Copy the blank workbook in app/templates. Use one row per event. Mark X under each calendar that needs it. Input dates include both the first and last day. Use stable codes and one unique request ID. Review the dates, names and link counts before approving a build. Blank selections leave existing links alone.

Correct and recover

Review the target and proposed edit before applying. If a submission stops, keep its workbook, request ID and local state together. Use Recovery to reconcile the saved operation before retrying. Calendar deletion is disabled. Shared event changes require additional checks.

Local files

Keep app/state, exports, recovery files, and private configuration on the authorized workstation. The launch URL contains a temporary session token and should remain private.
