# From workbook to reviewed operation

1. The operator selects an HTTPS origin. The launcher scopes saved state to the selected environment.
2. The workbook reader validates dates, unique codes and calendar membership. It converts inclusive workbook dates to the submission format.
3. A preview shows the requested records. The operator reviews the scope before submitting.
4. The creation adapter records progress. After interruption, the same request ID and workbook support reconciliation.
5. Calendar edits use a fresh record read and an Oracle version check. Shared-event edits have extra visibility requirements. Deletion stays disabled because the application cannot establish assignment eligibility.

The public edition supports the browser launcher as its entry point. Historical standalone pilot scripts retain offline regression fixtures with non-routable sample addresses. Real integration configuration belongs in a private tenant profile. Normal operation requires no AI service.
